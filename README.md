# AI/ML Internship - Assignment 3

## Project
Customer Churn Prediction using Deep Learning (TensorFlow/Keras)

## Project Overview
This project focuses on predicting customer churn using a Deep Learning model built with TensorFlow and Keras. The dataset was preprocessed, categorical variables were encoded, numerical features were scaled, and a neural network was trained to classify whether a customer is likely to churn.

## Contents
- 📓 Assignment3_MuhammadAwais.ipynb
- 🤖 customer_churn_model.keras

## Dataset
- **Name:** Telco Customer Churn Dataset
- **Original Records:** 7,043
- **Records After Cleaning:** 7,032

- Accuracy
- Precision
- Recall
- F1-Score

## Project Outcome
The trained deep learning model predicts whether a customer is likely to churn based on customer information. The final model is saved in `.keras` format and can be reused for future predictions without retraining.
